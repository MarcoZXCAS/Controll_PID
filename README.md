# Controll_PID
Libreria per Arduino e ESP, permette di eseguire un controllo proporzionale derivativo integrativo, usando una variabile double, dando un setpoint e input con la possibilità di rimuovere anche eventuali errori tramite dei constraint, si possono usare più controlli PID in un unico codice. 
L'uso può variare da un cambiamento di una variabile, alla velocità di un motore DC per avere un avviamento dolce e uno stop dolce.
La libreria è completamente stand-alone
